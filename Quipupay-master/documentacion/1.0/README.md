# Documentacion 1.0 - Quipupay

Esta carpeta contiene la documentacion base del proyecto Quipupay para la primera version academica.

## Contenido

- `gestion-git.md`: flujo de ramas, commits atomicos y reglas de integracion.
- `paleta-wcag.md`: paleta de colores y criterios de accesibilidad WCAG.
- `arquitectura-backend.md`: estructura inicial del backend.
- `base-datos-flyway.md`: arquitectura de base de datos, esquemas, ledger, biometria, auditoria y Flyway.
- `kyc-antifraude.md`: verificacion biometrica de identidad, motor de riesgo multi-senal y modelo de amenazas.
- `mockups-wireframes/README.md`: carpeta para subir mockups y wireframes.
- `unidad1-fundamentos-servicio-ti.md`: temario de la Unidad 1 (fundamentos, metricas, servicio, taller APF1) aplicado a Quipupay como caso real.

## Regla de equipo

La rama principal no debe recibir cambios directos. Las mejoras se trabajan por ramas y se integran mediante revision del Scrum Master.
