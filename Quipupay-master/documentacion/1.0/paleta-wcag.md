# Paleta de Colores y Accesibilidad WCAG

## Objetivo

Definir una base visual accesible para Quipupay, cuidando contraste, legibilidad y consistencia.

## Paleta principal

| Uso | Color | Hex | Comentario |
| --- | --- | --- | --- |
| Primario oscuro | Azul noche | `#0B1F3A` | Encabezados, navegacion, fondo institucional |
| Primario | Azul financiero | `#1D4ED8` | Botones principales y acciones |
| Secundario | Verde confianza | `#0F766E` | Estados positivos, confirmaciones |
| Alerta | Ambar | `#B45309` | Advertencias y estados pendientes |
| Error | Rojo | `#B91C1C` | Errores y bloqueos |
| Fondo claro | Gris suave | `#F3F4F6` | Fondos secundarios |
| Texto principal | Gris casi negro | `#111827` | Texto normal |
| Texto secundario | Gris medio | `#374151` | Ayudas y descripciones |
| Blanco | Blanco | `#FFFFFF` | Fondos y texto sobre colores oscuros |

## Reglas WCAG

- Mantener contraste minimo 4.5:1 para texto normal.
- Mantener contraste minimo 3:1 para texto grande e iconos relevantes.
- No usar solo color para comunicar estados; acompanar con texto o icono.
- Los botones deben tener estado normal, hover, focus, disabled y error cuando aplique.
- Los formularios deben mostrar mensajes claros para errores.
- Las areas tactiles en mobile deben tener tamano adecuado.
- La app debe ser usable con tamanos de fuente aumentados.

## Aplicacion en Quipupay

- Accion principal: azul `#1D4ED8` con texto blanco.
- Confirmacion: verde `#0F766E`.
- Advertencia: ambar `#B45309`.
- Error o bloqueo: rojo `#B91C1C`.
- Fondos: blanco o gris suave.
- Texto: gris casi negro.
